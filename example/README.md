# paychangu_flutter example

Minimal demo for the [paychangu_flutter](https://pub.dev/packages/paychangu_flutter) package.

## Run

```bash
cd example
flutter pub get
flutter run --dart-define=PAYCHANGU_SECRET_KEY=your_sandbox_secret
```

Get a sandbox key from the [PayChangu dashboard](https://developer.paychangu.com/docs/api-keys).
Never commit live secrets.
